# Java-DSA

My solutions while learning Java and data structures. I'm following the chapter order of Apna College's Sigma 10 course. Each folder is one chapter, and the code in it is written by me.

## How it's organised

- One folder per chapter, numbered like the course, for example `04-variables-and-data-types`.
- One file per question. The first line of each file is a comment with the question.
